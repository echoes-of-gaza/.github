# Echoes of Gaza

A collective memory archive for the places of Gaza — **Place → Many Memories → Many Contributors**.

Places may change or disappear; memories remain. Anyone can browse a map of Gaza's places and read their memories; contributors add approximately-dated memories with photos and optional anonymity. Every memory is reviewed before publishing and presented as a personal testimony.

Graduation project — University of Palestine, Faculty of Software Engineering & AI.

**Stack:** Flutter · Next.js · Supabase (Postgres, PostGIS, pgvector) · hybrid Arabic/English search
